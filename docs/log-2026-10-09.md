## 1. Estructura y Pantallas Generadas

El flujo de la app tiene 11 pantallas principales organizadas en 4 flujos:

### Flujo de Onboarding

- WelcomeScreen — Pantalla de bienvenida con logo Scrinium, cita de Keats y CTA de entrada

- SubscriptionForm — Selección de plan (Gratuito / Scriptorium / Académico)

- CompletionScreen (en App.tsx) — Confirmación de acceso con cita literaria y botón "Entrar a la Biblioteca"

- Núcleo: Biblioteca (HomeScreen)

- HomeScreen — Estantería principal con barra de búsqueda, categorías horizontales, tarjetas de libros y barra de navegación inferior (Biblioteca / Importar / Explorar / Perfil). Centro de navegación que orquesta todos los flujos secundarios.

### Flujo de Importación Digital

- FileManager — Gestor de archivos importados, con opciones de vista lista/cuadrícula y menú de importación

- GoogleDriveImport — Importación desde Google Drive con búsqueda y resultados de repositorios académicos (UNAM, JSTOR, Perseus)

- CameraInterface — Cámara para digitalizar páginas físicas con guía de encuadre

- ImageProcessing — Barra de progreso de OCR con detección de idioma

- TextRestoration — Vista de texto restaurado con herramientas de corrección y confianza OCR

- DocumentConfirmation — Confirmación antes de guardar con previsualización del documento

- SaveConfirmation — Confirmación de guardado exitoso con destino de carpeta

- FileUploadSuccess — Pantalla de éxito post-importación con acciones rápidas

### Flujo de Lectura

- DivineComedyReader — Lector a pantalla completa con panel de navegación de cantos, notas y marcadores

- BilingualViewer — Visor paralelo latín/español de Las Metamorfosis con paginación por versos, zoom y modo oscuro

- ListeningMode — Modo de audio con controles de reproducción, velocidad y visualizador de onda

## 2. Componentes Principales y Autolayouts

| Componente | Organización |
| --- | --- |
| TopBar | Row (logo-botón + título + acciones). Logo como <button> que navega a HomeScreen. |
| CategoryPills | Row horizontal con scroll, chips con estado activo/inactivo |
| BookCard | Column (imagen cover → autor → título → badge de idioma) |
| BookGrid | Grid 2 columnas con gap uniforme dentro de ScrollArea |
| BottomNavBar | Row fijo en la parte inferior, 4 tabs con ícono + etiqueta |
| ImportMenu | Modal/drawer con Column de opciones (ícono + label) separadas por dividers|
| BilingualRow | Row (número de línea) |
| AudioControls | Column centrado: wave visualizer → info de track → slider de progreso → Row de controles |
| OCRProgress | Column: header + barra de progreso animada + métricas de detección |

## 3. Tokens Clave

**Paleta de colores (custom vars, aplicados vía inline style)**

| Token | Valor | Uso |
| --- | --- | --- |
| --parchment| #F5EDD6 | Fondo principal de todas las pantallas |
| --cream| #FAF6EE | Fondos de cards, inputs, modales |
| --ink-charcoal| #1C1C1E | Texto principal, iconos, botones CTA |
| --gold-accent| #B8924A | Bordes decorativos, divisores, highlights activos |
| --sepia-medium| #8B7355 | Texto secundario, metadatos, etiquetas |
| --sepia-light| #D4C5A9 | Bordes suaves, separadores, estados inactivos |

**Tipografías**

| Rol | Fuente |
| --- | --- |
| Títulos display | Georgia, Garamond, serif — peso 400, tracking amplio |
| Logo Scrinium | Georgia itálica, size 22-24px |
| Cuerpo de texto | Georgia, serif — 1rem / 1.05rem, line-height 1.7 |
| Verso bilingüe | Georgia, serif — 14-15px por columna |
| UI labels / tabs | Sistema sans-serif (Tailwind default) — 11-12px |

**Espaciados y Radio**

| Token | Valor |
| --- | --- |
| Padding de pantalla | px-5 py-4 (20px / 16px) |
| Gap entre cards | gap-4 (16px) |
| Radio de cards | rounded-lg (8px) o rounded-sm (2-4px) para botones CTA |
| Radio de chips | rounded-full para pills de categoría |
| --radius (Tailwind) | 0.625rem |

**Punto de navegación universal:** El logo `Scrinium` en la TopBar es un `<button>` en todos los componentes que acepta onGoHome como prop, retornando siempre a HomeScreen independientemente del flujo activo (importación, lectura, visor bilingüe o modo audio).
